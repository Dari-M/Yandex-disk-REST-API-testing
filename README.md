# Yandex disk REST API testing
Тестовый проект по автоматизации тестирования REST API Яндекс.Диска, выполненный в рамках тестового задания на позицию стажёра в Яндекс Финтех.

- **ТРЕБОВАНИЯ:**
    - В рамках тестового задания необходимо:
        - разработать пример проекта автотестов для REST API Яндекс.Диска
        - использовать полигон и документацию API для разработки проверок
        - использовать стек Python 3, pytest и requests
        - реализовать тесты для методов GET, POST, PUT и DELETE
        - разместить проект на GitHub
        - обеспечить возможность локального запуска проекта
        - не использовать личный OAuth-токен
