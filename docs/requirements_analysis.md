## АНАЛИЗ ТРЕБОВАНИЙ

- **КРАТКИЙ АНАЛИЗ ТРЕБОВАНИЙ:**
    - **Объект тестирования:** Полигон Yandex REST API Disk
    - **Core user flow:** работа с файлами и папками.
    - **Выбранные для автоматизации API-операции:**
        - **POST** - создание папки
        - **PUT** -  загрузка файла
        - **DELETE** - удаление ресурса
    - **Дополнительно учитывается** получение статуса асинхронной операции через **GET**.
    - Для проверки API также учитывается корректная обработка ошибок и соответствующих HTTP-кодов.

---

- **МАТРИЦА ТРЕБОВАНИЙ К API:**

| ID | Требование/ операция | HTTP метод | в ТЗ |
| --- | --- | --- | --- |
| R-01 | Создание папки | POST | ✔ |
| R-02 | Загрузка файла | PUT | ✔ |
| R-03 | Получение метаданных ресурса | GET | ✔ |
| R-04 | Изменение имени ресурса | … | ❌ |
| R-05 | Перемещение ресурса | POST | ✔ |
| R-06 | Копирование ресурса | POST | ✔ |
| R-07 | Удаление ресурса | DELETE | ✔ |
| R-08 | Получение статуса операции | GET | ✔ |
| R-09 | Обработка ошибок | - | ✔ |

✔ - указано в ТЗ

❌ - не указано в ТЗ

… - HTTP-метод требует уточнения по доступной документации API и не используется в выбранном наборе автоматизированных проверок.
