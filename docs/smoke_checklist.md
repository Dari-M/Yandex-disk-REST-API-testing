## SMOKE ЧЕК-ЛИСТ

**Цель:** проверить работоспособность основного пользовательского flow работы с файлами и папками через Полигон REST API Яндекс.Диска.

---

- ПРЕДУСЛОВИЯ:
    - доступен тестовый OAuth-токен
    - Полигон REST API Яндекс.Диска доступен
    - на Диске создана тестовая папка для выполнения сценария

---
