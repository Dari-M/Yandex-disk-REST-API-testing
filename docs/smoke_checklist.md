## SMOKE ЧЕК-ЛИСТ

**Цель:** проверить работоспособность основного пользовательского flow работы с файлами и папками через Полигон Yandex REST API Disck.

---

- ПРЕДУСЛОВИЯ:
    - доступен тестовый OAuth-токен
    - Полигон Yandex REST API Disck доступен
    - на Диске создана тестовая папка для выполнения сценария

---

- **ЧЕК-ЛИСТ:**

| ID | Проверка | Результат |
| --- | --- | --- |
| S-00 | Проверить доступность API и OAuth-авторизацию: выполнить **GET /v1/disk**  | ✔ |
| S-01 | Создать папку с именем: **Smoke_test_01** | ✔ |
| S-02 | Изменить имя папки **Smoke_test_01** на **Смоук_тест01@** | ✔ |
| S-03 | Получение метаинформации папки с именем: **Смоук_тест01@** | ✔ |
| S-04 | Загрузить файл по URL: **https://en.wikipedia.org/wiki/Duck#/media/File:Bucephala-albeola-010.jpg** , с path: **disk:/Смоук_тест01@/image.jpg** в созданную папку | ✔ |
| S-05 | Создать вложенную папку с именем: **tests** | ✔ |
| S-06 | Переместить файл во вложенную папку **tests** | ✔ |
| S-07 | Переместить вложенную папку с файлом в корневую папку | ✔ |
| S-08 | Скопировать папку **tests** в корневую папку, имя скопированной папки: **tests_copy** | ✔ |
| S-09 | переместить скопированную папку **tests_copy** в папку  **Смоук_тест01@** | ✔ |
| S-10 | Переместить в корзину файл по path: **disk:/Смоук_тест01@/image.jpg** | ✔ |
| S-11 | Переместить в корзину папки:  **tests, Смоук_тест01@** | ✔ |
| S-12 | Просмотреть содержимое корзины | ✔ |
| S-13 | Очистить корзину | ✔ |

✔  - Smoke тест пройден

❌ - Smoke тест не пройден
