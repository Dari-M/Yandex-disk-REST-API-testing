## SMOKE ЧЕК-ЛИСТ

**Цель:** проверить работоспособность основного пользовательского flow работы с файлами и папками через Полигон Yandex REST API Disck.

---

- ПРЕДУСЛОВИЯ:
    - доступен тестовый OAuth-токен
    - Полигон Yandex REST API Disck доступен
    - на Диске создана тестовая папка для выполнения сценария

---

- **ЧЕК-ЛИСТ:**

| ID | Проверка | Результат |
| --- | --- | --- |
| S-00 | Проверить доступность API и OAuth-авторизацию: выполнить **GET /v1/disk**  | ✔ |
| S-01 | Создать папку с именем: **Dari_01** | ✔ |
| S-02 | Изменить имя папки **Dari_01** на **Даша@01** | ✔ |
| S-03 | Получение метаинформации папки с именем: **Даша@01** | ✔ |
| S-04 | Загрузить файл с именем **DUCK.jpg**  в созданную папку | ✔ |
| S-05 | Создать вложенную папку с именем: **all_DUCKS** | ✔ |
| S-06 | Переместить файл во вложенную папку **all_DUCKS** | ✔ |
| S-07 | Переместить вложенную папку с файлом в корневую папку | ✔ |
| S-08 | Скопировать папку **all_DUCKS** с файлом в корневую папку | ✔ |
| S-09 | переместить скопированную папку **all_DUCKS копия** в ****папку  **Даша@01** | ✔ |
| S-10 | Переместить в корзину файл **DUCK.jpg** в папке **all_DUCKS** | ✔ |
| S-11 | Переместить в корзину папки:  **Даша@01, all_DUCKS** | ✔ |
| S-12 | Просмотреть содержимое корзины | ✔ |
| S-13 | Очистить корзину | ✔ |

✔  - Smoke тест пройден

❌ - Smoke тест не пройден
