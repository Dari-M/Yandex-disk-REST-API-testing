## ПЛАН ТЕСТИРОВАНИЯ

- **ОБЛАСТЬ ТЕСТИРОВАНИЯ:**
    - Тестирование охватывает основные операции работы с файлами и папками, определенные в матрице требований к API.
    - **В рамках проекта выполняются:**
        - ручное smoke тестирование основного пользовательского flow
        - автоматизированное тестирование выбранных API-операций
        - проверка успешных и основных негативных сценариев
        - проверка результатов выполнения операций и, при необходимости, статуса асинхронных операций

---

- **СТРАТЕГИЯ ТЕСТИРОВАНИЯ:**
    - **Smoke тестирование.**
    - Ручная проверка основного пользовательского flow работы с файлами и папками:
        - создание папки
        - загрузка файла
        - изменение имени ресурса
        - создание вложенной папки
        - перемещение файла и папки
        - копирование ресурса
        - удаление файла и папки
    - **Автоматизированное тестирование.**
    - Автоматизированное тестирование выбранных API-операций:
        - успешное создание ресурса
        - обработка попытки создания уже существующего ресурса
        - получение ссылки для загрузки файла и загрузка файла по полученному URL
        - проверка загрузки некорректного или отсутствующего файла
        - успешное удаление ресурса
        - обработка удаления несуществующего ресурса
        - проверка кодов ответов и структуры ответов API
        - проверка обработки ошибок авторизации
        - проверка статуса асинхронной операции при его наличии

---

<aside>
🐣
Цель Smoke тестирования - убедиться, что основные операции последовательно выполняются в рамках одного пользовательского сценария.

</aside>

---

- **ТЕСТОВОЕ ОКРУЖЕНИЕ:**
    - **API:** Яндекс API Диска
    - **Базовый URL:** https://cloud-api.yandex.net/v1/disk
    - **Авторизация:** OAuth-токен
    - **Инструмент ручного тестирования:** Полигон Yandex REST API Disk
    - **Язык автотестов:** Python 3.14
    - **Библиотека для HTTP-запросов:** requests
    - **Фреймворк автоматизированного тестирования:** pytest
    - **Среда разработки:** PyCharm
    - **Формат данных:** JSON
    - **Контроль версий:** Git / GitHub

---

- **РЕЗУЛЬТАТЫ ТЕСТИРОВАНИЯ:**
    - **По результатам тестирования формируются следующие артефакты:**
        - Smoke чек-лист
        - набор автоматизированных тестов выбранных API-операций
        - Bug Reports (при обнаружении дефектов)
        - журнал наблюдений в процессе тестирования
        - итоговый отчет по результатам тестирования
